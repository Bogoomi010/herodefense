# 스킬 메뉴 기획

2026-09-27 정의(초안). 플레이어 스킬트리 규칙은 [PLAYER_SKILL_TREE.md](PLAYER_SKILL_TREE.md), 영웅 본체는 [HERO.md](HERO.md)를 따른다. "현재 안"은 테스트 플레이로 바꿀 수 있다.

## 핵심

**스킬 메뉴 하나에 탭 두 개: 플레이어 스킬트리 | 영웅 기술.**

| | 플레이어 스킬트리 | 영웅 기술 |
|---|---|---|
| 무엇 | 게임 전체 유틸 (포탑·경제·강림) | 필드에서 영웅이 직접 쓰는 기술 |
| 쓰는 곳 | 스테이지 내내 자동 적용 (패시브) | 필드 시점에서 키로 발동 (액티브) |
| 모양 | 노드 그래프 (가운데에서 사방으로) | 영웅 고르기 + 그 영웅의 기술 카드 목록 + 장착 칸 2개 |
| 포인트 | 스킬 포인트 | **같은 스킬 포인트** (현재 안) |
| 초기화 | 무료, 탭별로 | 무료, 탭별로 |

- **포인트를 하나로 쓴다 (현재 안).** 플레이어 자신이 영웅이다([HERO.md](HERO.md) 핵심). 레벨업으로 얻은 포인트를 유틸에 쓸지 영웅 기술에 쓸지가 곧 플레이 방식 선택이다. 영웅 레벨·영웅 포인트를 따로 두지 않는다.
- **강림 효과는 플레이어 스킬트리에 남는다.** 강림 피해·강림 쿨타임은 지금처럼 영웅 가지 노드다([PLAYER_SKILL_TREE.md](PLAYER_SKILL_TREE.md) 스킬 목록). 영웅 기술 탭은 필드에서 누르는 기술만 다룬다.

## 여는 곳

1. **스테이지 선택 화면의 "스킬" 버튼**으로 연다 (지금 버튼 그대로).
2. 메뉴 화면에서만 연다. 스테이지 도중에는 열 수 없다 (플레이어 스킬트리 규칙과 같다).
3. **튜토리얼을 마치면 열린다.** 두 탭이 함께 열린다.
4. 마지막으로 본 탭을 기억한다. 처음 열면 플레이어 스킬트리 탭.
5. 쓰지 않은 포인트가 있으면 "스킬" 버튼에 점(●)을 띄운다.

## 화면 배치

| 위치 | 내용 |
|---|---|
| 위 왼쪽 | 탭: **플레이어 스킬트리** / **영웅 기술** |
| 위 가운데 | 레벨 N · 경험치 막대 (현재/필요) |
| 위 오른쪽 | **남은 스킬 포인트** (두 탭 공통, 한 번만 표시) |
| 가운데 | 탭 내용 (아래 절) |
| 오른쪽 | 설명 칸: 마우스를 올린 노드·기술의 이름, 효과, 다음 단계 수치, 비용 |
| 아래 | 이 탭 초기화 · 돌아가기 (ESC) |

- 초기화는 **지금 보고 있는 탭만** 되돌린다. 누르면 "N포인트를 돌려받습니다" 확인 창.

## 영웅 기술 탭

### 구성

**탭 맨 위에서 영웅(검사·거너·마법사·궁수)을 고른다.** 아직 열리지 않은 영웅은 어둡게, "스테이지 N 클리어"를 적는다. 잠긴 영웅의 기술 목록도 볼 수는 있지만 배울 수 없다. 기술 목록·배운 단계·장착은 영웅마다 따로다. 스킬 포인트는 모든 영웅과 플레이어 스킬트리가 함께 쓴다 (현재 안).

```
[검사] [거너] [마법사] [궁수]   ← 영웅 고르기
┌ 기술 카드 목록 ───────────────────────┐  ┌ 설명 칸 ─────┐
│ [회오리 베기 ★★☆] [돌진 ☆☆☆ 잠김] ... │  │ 이름·쿨타임  │
│ [전투 함성 ★☆☆]  [창 던지기 ☆☆☆]     │  │ 단계별 수치  │
└───────────────────────────────────────┘  │ 배우기 / 강화│
┌ 장착 칸 ────────────┐                     └──────────────┘
│  [Q: 회오리 베기]  [E: 전투 함성]  │
└─────────────────────┘
```

1. **기술 카드.** 기술마다 카드 한 장: 아이콘, 이름, 단계(★ 3칸), 쿨타임.
   - 배움: 밝게, 단계만큼 ★.
   - 배울 수 있음: 테두리 강조, "1포인트".
   - 잠김: 어둡게, 조건("스테이지 N 클리어")을 적는다.
2. **배우기·강화.** 카드를 고르고 설명 칸의 버튼을 누른다. 단계마다 스킬 포인트 1점, 최대 3단계 (현재 안).
3. **장착 칸 2개: Q, E.** 배운 기술만 넣는다. 카드를 칸으로 끌거나, 카드를 고른 뒤 칸을 누른다. 같은 기술은 한 칸에만. 빈 칸 허용.
   - 장착은 포인트가 들지 않고 메뉴에서 언제든 바꾼다.
   - 기술을 처음 배우면 빈 칸에 자동으로 넣는다.
4. **초기화**하면 **지금 고른 영웅의** 배운 기술과 장착이 모두 비고 포인트를 돌려받는다. 첫 기술("처음부터")은 1단계로 남고 Q에 다시 들어간다.

### 검사 기술 (초안)

| 기술 | 효과 (1단계) | 단계마다 | 쿨타임 | 해금 |
|---|---|---|---|---|
| 회오리 베기 | 영웅 주변 3m 크립에게 피해 40 | 피해 +20 | 8초 | **처음부터** (1단계로 배워 있음, Q 장착) |
| 돌진 | 바라보는 방향으로 8m 돌진, 지나간 크립에게 피해 30 + 옆으로 밀침 | 피해 +15, 3단계에 쿨타임 −2초 | 10초 | 스테이지 2 클리어 |
| 전투 함성 | 영웅 주변 10m 포탑의 공격 간격 −25%, 6초 | 지속 +2초 | 20초 | 스테이지 3 클리어 |
| 창 던지기 | 바라보는 방향으로 창을 던져 처음 맞은 크립 하나에 피해 150 (사거리 20m) | 피해 +75 | 12초 | 스테이지 4 클리어 |

- 역할이 겹치지 않게 한 가지씩: 근접 광역 피해 / 이동 / 포탑 지원 / 원거리 단일 고피해(보스 대응).
- 창 던지기는 보스용이다. 포탑과 영웅 기본 공격만으로 보스를 잡기 어려웠다(2026-09-27 보스 HP 절반 조정).
- 밀침은 기존 규칙을 쓴다: 밀려난 크립의 길 복귀([CREEP_MOVEMENT.md](CREEP_MOVEMENT.md)).
- 피해는 크립 피격 표시(빨강 번쩍임)를 따른다.

## 인게임 연결

- **키는 Q, E** (2026-09-27 확정). **R은 비워 둔다** — 총을 쓰는 캐릭터가 나오면 장전 키로 쓴다.
- **상호작용(업그레이드·나무 베기)은 E → F로 옮긴다** (2026-09-27 확정). E를 기술에 쓰기 때문.
- **필드 시점 행동 줄**에 Q, E 칸을 더한다: 기술 아이콘, 남은 쿨타임(숫자 + 어둡게 차오르는 칸). 빈 칸이면 칸을 숨긴다. 기록은 [INGAME_UI.md](INGAME_UI.md) 행동 줄.
- **절벽 시점에서는 쓰지 않는다.** 필드에 강림했을 때만 발동한다.
- 쿨타임은 강림·귀환과 같이 **실제 시간**이다 (배속 영향 없음).
- 스테이지 시작 시 모든 기술 쿨타임은 0 (바로 쓸 수 있음). 귀환해도 쿨타임은 계속 돈다.

## 저장

저장 슬롯(`PlayerProfile`)에 더한다. 슬롯마다 따로.

| 값 | 뜻 |
|---|---|
| 배운 기술 | 영웅마다: 기술 id → 단계 (1~3) |
| 장착 | 영웅마다: Q 칸 기술 id, E 칸 기술 id (빈 칸은 비움) |
| 마지막 탭 | 플레이어 / 영웅 (없어도 됨 — 없으면 처음 열 때 플레이어 탭) |

스킬 포인트는 지금 `skillPoints` 하나를 두 탭이 함께 쓴다.

## 뺀 것

- 영웅 레벨·영웅 전용 포인트 (포인트 하나로 충분, 필요해지면 다시 본다).
- 영웅 고르기(스테이지에 들고 갈 영웅)는 스테이지 선택 화면에서 한다. 스킬 메뉴의 영웅 고르기는 어느 영웅의 기술을 볼지 고르는 것뿐이다.
- 기술끼리의 연계·조합, 기술 트리(기술 안의 갈래).
- 대지 강타(앞쪽 크립 스턴): 강림 효과(스턴 + 에어본)와 겹쳐서 뺐다 (2026-09-27).
