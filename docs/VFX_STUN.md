# 스턴 이펙트 (머리 위 빙글빙글 별)

크립이 스턴에 걸려 있는 동안 머리 위에서 작은 별 3개가 원을 그리며 돈다. 만화에서 "어질어질"을 표현하는 방식이다. 스턴 시간이 2초로 짧기 때문에, 이펙트가 뜨는 순간 바로 알아볼 수 있어야 한다.

## 언제

- `MobState.IsStunned(now)`가 참인 동안 보인다. 거짓이 되면 사라진다.
- 지금 스턴을 거는 곳: 영웅 강림 착지(일반 크립은 뒤집혀 떨어진 순간부터 2초, 보스는 강림 순간부터 1초, [HERO.md](HERO.md#강림-효과)).
- 앞으로 스턴을 거는 포탑이나 스킬이 생겨도 같은 이펙트를 쓴다. 조건은 `IsStunned` 하나다.

## 모양

| 항목 | 값 |
|---|---|
| 구성 | 노란 별 3개, 서로 120° 간격. 별들을 잇는 얇은 궤도 원(연노랑, 두께 0.03m × 크기)이 함께 보인다 |
| 별 | 두께가 조금 있는 로우폴리 3D 별. 크립 모델과 같은 톤이고, 약하게 발광(Glow 머티리얼)시켜 어두운 면에서도 보이게 |
| 크기 | 별 반지름 0.18m × 크립 크기. 0.1m는 한 화면에 여러 마리가 보이는 거리에서 점으로만 보였다 |
| 궤도 | 머리 위 수평 원. 반지름 0.45 × 크립 크기. 카메라가 비스듬히 보므로 화면에서는 납작한 타원으로 보인다 |
| 회전 | 궤도 한 바퀴 0.9초. 별도 제자리에서 돈다(한 바퀴 0.6초) |
| 흔들림 | 별마다 위아래로 살짝 출렁인다(±0.03, 박자를 서로 다르게) |
| 앞뒤 | 3D라서 머리 뒤로 지나가는 별은 머리에 가려진다. 따로 처리할 필요 없다 |

## 위치

- 머리 꼭대기에서 조금 위. HP 바보다는 아래에 둬서 두 요소가 겹치지 않게 한다.
- **뒤집혀 있을 때:** 누우면 머리가 땅 쪽으로 가서 머리 위 별이 몸에 가려 보이지 않았다(2026-09-27 수정). 그래서 뒤집히면 별은 **하늘을 향한 배(모델 하단) 위, 위로 뻗은 다리 사이**(발밑에서 몸 높이 × 0.85, `FlippedStarHeight`)에 뜬다. HP 바는 서 있을 때 높이를 유지한다. 궤도는 항상 월드 기준 수평이다(크립과 같이 뒤집히지 않는다).
- 보스는 크기에 비례해 궤도와 별이 커진다.

## 등장·퇴장

| 구간 | 연출 |
|---|---|
| 등장 | 0.1초 동안 크기 0 → 1.15 → 1 (톡 튀어나옴) |
| 유지 | 스턴 시간 동안 계속 돈다 |
| 퇴장 | 0.15초 동안 크기 1 → 0. 스턴이 끝나 일어나는 순간과 맞춘다 |
| 다시 걸림 | 이미 떠 있으면 등장 연출 없이 시간만 늘어난다 |

## 구현 방향

- 파티클·프리팹을 쓰지 않는다. HP 바처럼 `EnemyView`가 코드로 만든다(`BuildStun`/`TickStun`). 회전하는 빈 오브젝트 "Stun" 아래에 별 3개와 궤도 원(`LineRenderer`, 루프)을 둔다.
- 별 메시는 코드로 만든 두께 있는 오각 별(`StarMesh`)이다. 노란 Lit 머티리얼에 약하게 발광을 준다. 모든 크립이 같은 메시와 머티리얼을 함께 쓴다.
- 위치는 모델 리그의 `Head` 본([make_farm.py](../Tools/Blender/make_farm.py)) + 위로 0.6 × 크기. 걷기 애니메이션으로 머리가 끄덕여도 따라간다. 본이 없는 캡슐은 몸 위에 띄운다.
- 조절 값은 `EnemyView` 상단 상수(`StarOrbit`, `StarSize`, `StarAbove`, `OrbitDegPerSec`, `SpinDegPerSec`, `PopInSec`, `PopOutSec`)에 모여 있다.

## 정한 것

- 새(병아리)가 아니라 별을 쓴다. 구역 테마와 상관없이 똑같다.
- 스턴은 원인(강림, 포탑 등)과 상관없이 모두 같은 이펙트(노란 별)로 통일한다.
