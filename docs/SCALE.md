# 크기(스케일) 기획

2026-09-26 정의. 단위: 1 Unity 단위 = 1m.

## 확정

| 대상 | 크기 |
|---|---|
| 영웅 | 일반 사람 크기 (약 1.8m) |
| 포탑 | 풍차 정도 크기의 건축물 |
| 크립 | 사람 크기(1.8m)부터 1.5배(2.7m)까지 |

## 현재 구현 (2026-09-26)

| 대상 | 현재 | 확정 크기와 비교 |
|---|---|---|
| 영웅 | 캡슐 2m | 거의 맞음 |
| 크립 | 0.8m × 단계 1.0~1.4 = 0.8~1.1m, 보스 1.8m | 절반 이하로 작음 |
| 포탑 | 0.7 × 1.2 × 0.7m 큐브 | 10배 가까이 작음 |
| 타일 | 1.5m, 길 평지 폭 약 1m | 사람 크기 크립이 나란히 못 지나감 |
| 맵 | 20 × 12 타일 = 30 × 18m | 풍차 포탑 몇 개로 가득 참 |

크립과 포탑을 키우면 길 폭, 맵 크기, 포탑 사거리·구역, 영웅 이동 속도, 카메라 구도가 함께 바뀌어야 한다.

## 확정 값 (2026-09-26 적용)

| 대상 | 값 | 근거 |
|---|---|---|
| 크립 | 1.8 ~ 2.7m | 확정 |
| 영웅 | 1.8m | 확정 |
| 포탑 | 높이 10~12m, 밑면 지름 약 3m (`footprintRadius` 1.5m) | 작은 풍차 |
| 포탑 구역 (`zoneRadius`) | 5m | 지금 비율(바닥의 약 3.3배)을 유지 |
| 포탑 상호작용 범위 | 5m | 영웅이 포탑 밑에 다가갈 수 있는 거리 |
| 포탑 사거리 | 15m 안팎 | 풍차 높이에서 길 여러 구간을 내려다보는 정도 |
| 나무 | 높이 6~8m, 바닥 반지름 1m | 실제 나무 |
| 타일 | 4m (길 평지 폭 약 3m) | 사람 크기 크립이 2~3마리 나란히 걸을 수 있게 |
| 맵 | 20 × 12 타일 = 80 × 48m | 타일 수는 그대로, 타일만 키움 |
| 보스 | 크립 최대(2.7m)보다 큼, 예: 4~5m | 보스는 크고 느리다(STAGE.md) |

## 적용 내용

- **거리 단위 상수:** `GameConfig.PxToWorld`를 맵과 같은 배율(8/3)로 바꿨다(1m = 50px → 18.75px). 원본에서 가져온 px 단위 속도·사거리가 모두 같은 배율로 커져, 크립이 길을 건너는 시간과 사거리/맵 비율이 이전과 같다. 크립 속도는 약 3~4m/s(달리는 가축 정도)가 된다.
- **크립:** 기본 높이 1.8m, 단계별 1.0 / 1.25 / 1.5배. 보스 2.2배(약 4m). 크립 간격 1.1m, 길 반폭 1.6m.
- **포탑:** 바닥 반지름 1.5m, 구역 5m, 상호작용 5m, 사거리 280px(약 15m). 모델이 없어 3 × 11 × 3m 상자로 대신한다.
- **나무:** 기존 배치를 맵과 같은 배율로 옮기고 3.2배로 키웠다(약 2.6~7.7m). 바닥 반지름 1m, 상호작용 3m.
- **영웅:** 크기 그대로(2m 캡슐). 이동 속도 9m/s, 공격 사거리 약 6.4m, 넉백 반경 3m.
- **절벽·영웅 거점·카메라 앵커:** 맵 원점 기준으로 같은 배율로 늘려 절벽 시점 구도를 유지했다.
- **지형:** 타일 4m, 높이 진폭 1.9m, 노이즈 주파수를 맵 배율만큼 낮춰 언덕 모양을 유지했다.

## 알려진 문제

- **3인칭 카메라가 포탑에 가려진다.** 포탑이 11m로 커지면서 영웅 뒤 카메라가 포탑 안으로 들어갈 수 있다. 카메라 가림 처리는 아직 없다.
- 크립 모델(양)이 사람 키로 커져 어색할 수 있다. 크립 종류 기획에서 모델을 정한다.
