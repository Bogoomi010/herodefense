# 포탑 업그레이드 기획

2026-09-23 정의. 베타 테스트 범위. 용어는 [TOWER_PLACEMENT.md](TOWER_PLACEMENT.md#용어), 상호작용 공통 규칙은 [HERO_INTERACTION.md](HERO_INTERACTION.md)를 따른다.

## 베타 범위

- 포탑 종류는 **1가지**: 일반 공격 포탑.
- 업그레이드 방향은 **3가지**:

| 방향 | 효과 |
|---|---|
| 공격속도 | 공격 간격이 짧아진다 |
| 파워 | 한 발의 피해량이 커진다 |
| 독 | 맞은 적에게 일정 시간 지속 피해를 준다 |

## 진행 방식

1. 플레이어가 영웅으로 필드에 강림한다. 절벽 시점에서는 업그레이드할 수 없다.
2. 영웅이 포탑의 **상호작용 범위**(`interactRadius`) 안으로 들어가면 상호작용 안내가 뜬다.
3. **상호작용 키**를 누르면 3가지 방향 중 하나를 고르는 선택 창이 열린다.
4. 방향을 고르면 업그레이드가 시작된다. 영웅은 **10초 이상**(단계가 오를수록 길어짐, 현재 안 10 → 15 → 20초) 동안 상호작용 범위 안에 머물러야 한다. 진행 막대를 보여 준다.
5. 시간이 다 차면 업그레이드가 끝나고, 포탑은 고른 방향에 맞게 강해진다.

## 규칙

- **비용은 골드.** 시작할 때 잔액을 확인하고(모자라면 시작할 수 없다), 완료할 때 낸다. 도중에 취소하면 골드를 잃지 않는다.
- 골드는 스테이지 안에서만 쓰는 자원이다. 스테이지가 끝나면 0으로 초기화된다.

- 취소·대상 선택 등은 [HERO_INTERACTION.md](HERO_INTERACTION.md)의 공통 규칙을 따른다.

## 미정

- 방향마다 몇 단계까지 올릴 수 있는가? 한 포탑이 세 방향을 모두 올릴 수 있는가, 아니면 하나만 골라야 하는가? (현재 안: 세 방향 모두 가능)
- 방향·단계별 골드 비용
- 업그레이드 중에도 포탑은 계속 공격하는가?
- 방향별 수치 (공속 증가율, 피해 증가율, 독 피해량·지속시간)
