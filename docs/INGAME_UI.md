# 인게임 UI 기획

2026-09-26 정의. 조사 자료: [INGAME_UI_RESEARCH.md](INGAME_UI_RESEARCH.md).

## 원칙

1. **위 줄은 두 시점 공통, 아래 줄만 바뀐다.** 절벽 시점(설치)과 필드 시점(영웅 강림)을 오가도 위 줄은 그대로다. 아래 줄을 보면 지금 어느 모드인지 안다.
2. **가운데는 비운다.** 화면 가운데에는 필드 위 안내(상호작용 키, 진행 막대)와 업그레이드 선택 창만 뜬다.
3. **자주 쓰는 것은 키를 준다.** 포탑 종류 1~4, 설치 B, 웨이브 시작 Space, 상호작용 E, 귀환 T, 업그레이드 방향 1~3.
4. **수치는 한 번만.** 같은 수치를 글과 그래프로 두 번 보여 주지 않는다.

## 배치

| 위치 | 절벽 시점 | 필드 시점 |
|---|---|---|
| 왼쪽 위 | 골드 · 데스 · 웨이브 n/15 (보스 스테이지 마지막 웨이브는 "보스") · **남은 크립** | 같음 |
| 가운데 위 | 별 3개 + 경과 시간 / 별 기준 시간, 그 아래 알림(3초) | 같음 |
| 오른쪽 위 | 배속 1× / 2×, 스테이지 종료(베타용), 다음 웨이브(번호·남은 초·"지금 시작") 또는 진행 중 남은 초 | 같음 + "절벽 비움 · 포탑 설치 불가" |
| 왼쪽 아래 | 영웅 칸: "영웅 강림", 쿨타임 막대, 대기 초 또는 "Ctrl+클릭으로 필드에 내려가기" | 영웅 칸: "영웅 · 필드", 귀환 대기 막대, "귀환 가능까지 N초" 또는 "T로 절벽에 돌아가기" |
| 아래 가운데 | **포탑 줄**: 1~4 칸(이름, 비용). 잠긴 칸은 "잠김 · 스테이지 N". 골드가 모자라면 비용이 빨강. 고른 칸은 테두리. 위에 설치 안내 | **행동 줄**: 좌클릭 공격, E 상호작용(가까운 대상에 따라 "업그레이드"/"나무 베기"), T 귀환(대기 초). 쓸 수 없는 키는 흐리게 |
| 필드 위 | 설치 미리보기(초록/빨강 원, [TOWER_PLACEMENT.md](TOWER_PLACEMENT.md)). 클릭해 고른 포탑의 사거리 원과 테두리 | 대상 머리 위에 상호작용 안내와 진행 막대. 머리가 화면 밖이면 화면 안으로 붙잡는다 |
| 가운데 | 정산 창 | 업그레이드 선택 창 |

## 요소별 규칙

### 남은 크립

- **남은 크립 = 필드에 있는 크립 + 이번 웨이브에서 아직 나오지 않은 크립.**
- 보스도 크립 하나로 센다. 황금 비둘기도 필드에 있으면 센다.
- 휴식 중에는 필드에 남은 크립만 센다.

### 별

- 지금 클리어하면 받을 별을 보여 준다. 크립이 하나라도 통과하면 하나, 별 기준 시간을 넘기면 하나 꺼진다([STAGE.md](STAGE.md) 별 규칙).

### 다음 웨이브

- 휴식 중: "다음 웨이브 N · M초"와 "지금 시작 (Space)" 버튼. 누르면 남은 휴식을 건너뛰고 바로 시작한다.
- 진행 중: "웨이브 진행 중 · M초". 마지막 웨이브는 "마지막 웨이브".
- 일찍 시작해도 보상은 없다(현재 안).

### 배속

- 1×와 2×. 크립·포탑·웨이브 시간에만 적용된다. 영웅 이동·공격, 업그레이드·나무 베기 진행 시간, 강림·귀환 쿨타임은 실제 시간 그대로다.

### 업그레이드 선택 창

- 방향 3개를 한 줄로 놓고, 칸마다 **단계, 바뀌기 전후 수치, 비용, 걸리는 시간**을 적는다.
  - 공격속도: 공격 간격 (예: 0.70 → 0.56초)
  - 파워: 한 발 피해 (예: 14 → 18)
  - 독: 초당 독 피해 (예: 0 → 4)
- 골드가 모자란 방향은 비용을 빨갛게 쓴다. 눌러도 "골드 부족" 알림만 뜨고 시작하지 않는다.
- 최대 단계는 "최대 단계".
- 창 아래에 "범위를 벗어나면 취소 · 골드는 완료할 때 냄 · E/ESC 닫기".

### 포탑 고르기 (절벽 시점)

- 설치 모드가 아닐 때 포탑을 **좌클릭하면 그 포탑을 고른다.**
- 고른 포탑은 **공격 사거리 원**(바닥, 노란색)과 **테두리**(노란색)를 보인다. 테두리로 지금 고른 대상임을 나타낸다.
- 한 번에 하나만 고른다. 다른 포탑을 클릭하면 그쪽으로 옮긴다.
- **해제:** 빈 곳 좌클릭, 우클릭, ESC, 설치 모드 켜기, 영웅 강림.
- Ctrl+클릭은 영웅 강림이라 고르기에 쓰지 않는다.

### 정산 창

- 결과, 별, 시간, **처치 수**, 통과한 크립, 보상. 정산 중에도 위 줄은 보인다.

## 뺀 것

- 처치 수, 플레이어 레벨, 킬 스트릭은 HUD에서 뺐다. 처치 수는 정산 창에 있다.
- 미니맵, 일시정지, 일찍 부르기 보상, 새 포탑·새 적 소개 카드, 영웅 체력(영웅 체력 기획이 없음), 영웅 스킬 칸(미정).

## 구현 (2026-09-26)

- IMGUI 그대로. 공용 배치·그리기는 `Hud` (`Game/EnemySpawner.cs` 아래쪽). 위치는 화면 크기에서 계산하고, 설치 클릭 막기(`EnemySpawner.IsOverHud`)도 같은 위치를 쓴다.
- 위 줄·포탑 줄·정산 창: `EnemySpawner.OnGUI`. 영웅 칸·행동 줄·필드 위 안내·업그레이드 선택 창: `HeroInteractor.OnGUI`.
- 남은 크립: `EnemySpawner.CreepsLeft` = 필드 크립 + `WaveSystem.ToSpawn`. 지금 시작: `WaveSystem.StartNow`.
- 포탑 고르기: `TowerPlacer.UpdatePick` / `TowerPlacer.TowerAt`(포탑에 콜라이더가 없어 메시 경계 상자로 판정), 표시는 `Tower.SetSelected`. 테두리는 `Rings.Outline`(메시를 조금 키운 복제의 뒷면만 그리는 방식).
