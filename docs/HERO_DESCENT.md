# 영웅 강림 기획

2026-09-23 정의. 필드에서 하는 작업은 [HERO_INTERACTION.md](HERO_INTERACTION.md)를 따른다.

## 흐름

1. 기본 시점: 영웅이 필드 밖 절벽 위에 서 있다(오버더숄더).
2. **강림:** 필드의 지점을 골라 영웅을 내려보낸다. 착지하면 카메라가 3인칭으로 바뀐다. 단순히 뛰어드는 것이 아니라 **운석처럼** 떨어진다(아래 "강림 연출").
3. **귀환:** 강림 후 **10초**가 지나야 귀환 키(T)로 절벽에 돌아갈 수 있다.
4. **강림 쿨타임:** 귀환한 뒤 **20초**가 지나야 다시 강림할 수 있다.

## 강림 연출 (2026-09-27)

1. **솟구침 (0.45초):** 절벽에서 하늘 높이 솟구친다. 처음엔 빠르고 정점에 가까울수록 느려진다.
2. **정점 (0.1초):** 절벽·착지점 중 높은 쪽보다 18m 위, 착지점에서 절벽 쪽으로 6m 물러난 자리에서 잠깐 멈춘다.
3. **내리꽂힘 (0.22초):** 갈수록 빨라지며 비스듬히 착지점을 내리찍는다.
4. **착지:** [강림 효과](HERO.md#강림-효과)가 발동하고, 바닥에 충격파 원이 강림 지역 끝(5m)까지 퍼지며 사라진다(0.3초). 카메라가 0.35초 흔들린다.
- 강림하는 동안 카메라는 절벽 자리에 머문 채 영웅을 눈으로 좇는다(하늘로 올려다봤다가 착지점으로 내려옴). 착지 후 3인칭으로 옮겨 간다.
- 수치: `Hero.riseSec`, `hangSec`, `slamSec`, `apexHeight`, `slamBack`, 흔들림 `HeroCamera.shakeAmp`, `shakeSec`.

## 수치

| 항목 | 기본값 | 조절 |
|---|---|---|
| 강림 쿨타임 | 20초 | [플레이어 스킬](PLAYER_SKILL_TREE.md) "영웅 강림 쿨타임 단축"으로 줄어든다 |
| 귀환 가능까지 | 10초 | 없음 |

## 구현 상태

- 귀환 대기 10초: 구현됨 (`Hero.returnCooldownSec`).
- 강림 쿨타임 20초: 미구현.
