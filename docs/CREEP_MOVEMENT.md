# 크립 이동 기획

2026-09-26 정의.

## 의도

크립이 한 줄로 행진하는 대신, **동물 무리(소 떼)처럼** 길 폭 안에서 퍼져 흐르게 한다. 폭발에 맞으면 날아갔다가 다시 무리로 돌아오는 모습으로 자연스러운 동물 이동 느낌을 준다.

## 현재 (2026-09-26)

- 경로는 `PathGenerator`가 만든 타일 경로다(무작위 DFS로 판 한 줄 길).
- 크립은 경로 타일 중심을 이은 선(`PathFollower`) 위를 **한 줄로, 같은 속도로** 이동한다. 위치는 "경로 시작에서 몇 m 왔는가"(`MobState.Dist`) 하나로 정해진다.

## 규칙

1. **무리 이동.** 크립은 경로 중심선이 아니라 **길 폭 안 어디든** 지나갈 수 있다. 무리 전체는 도착점을 향해 흐른다.
   - 서로 겹치지 않게 밀어낸다.
   - 개체마다 속도와 좌우 위치가 조금씩 다르다.
   - 평소에는 길(경로 타일) 밖으로 나가지 않는다.
2. **넉백.** 플레이어(영웅)의 공격이나 **폭발형 포탑**의 폭발 범위에 있던 크립은 폭발 중심에서 바깥쪽으로 **날아간다**. 길 밖 잔디까지 날아갈 수 있다.
3. **복귀.** 날아간 크립은 착지한 뒤 **가장 가까운 길**로 돌아와 무리 이동을 이어 간다.
   - 가장 가까운 길은 **날아가기 전 위치의 앞뒤 3m 안**에서만 찾는다. 구불구불한 길에서 잔디를 건너 이웃한 다른 구간(훨씬 앞)으로 건너뛰지 않게 하기 위해서다.

## 구현 (2026-09-26)

| 항목 | 현재 값 / 방식 |
|---|---|
| 길 폭 | 타일 폭의 80% (반폭 1.6m) 안에서 좌우로 퍼짐 |
| 무리 느낌 | 개체마다 속도 ±12%, 1.5~3.5초마다 새 좌우 위치를 골라 천천히 흘러감(0.35m/s) |
| 밀어내기 | 크립끼리 1.1m 안으로 붙지 않게 (`EnemySpawner.creepSpacing`) |
| 넉백 | 폭발 중심에서 바깥으로 포물선, 가장자리는 중심의 절반 세기. 맵 밖으로는 안 나감 |
| 영웅 공격 | 맞은 크립 주변 3m 폭발 넉백 (`Hero.knockRadius`, `knockForce`) — 피해는 맞은 한 마리만 |
| 보스 | 날아가지 않음 |
| 날아가는 동안 | 공격받을 수 있음. 투석기·영웅 공격 넉백은 착지 후 멈칫 없이 바로 복귀. **영웅 강림 에어본**은 공중에서 뒤집혀 떨어지고, 착지 순간부터 스턴 1초 → 끝나면 바로 일어나 복귀 ([HERO.md](HERO.md#강림-효과)) |
| 코드 | `EnemyView`(이동 상태: 길 / 공중 / 복귀), `EnemySpawner.Separate`·`Explode`, `PathFollower.Closest` |

## 미정

- **넉백 세기:** 폭발 중심에 가까울수록 멀리 날아가는가? 크립 종류(무게)에 따라 다른가?
- **보스:** 보스도 날아가는가? (구현: 날아가지 않음)
- **날아가는 동안:** 투석기·영웅 공격 넉백도 착지 후 뒤집힘 + 스턴을 줄 것인가? (구현: 영웅 강림만)
- **복귀 지점과 진행도:** 앞뒤 3m 안에서 복귀하므로 최대 3m 앞당겨지거나 밀린다. 뒤로만 밀리게 할 것인가?
- **포탑 위로 날아가면:** 포탑·나무에 부딪혀 멈추는가, 통과하는가?
- **영웅의 어떤 공격이 넉백인가:** 영웅의 모든 공격인가, 특정 스킬만인가?
- **폭발형 포탑:** 아직 없다(베타는 일반 공격 포탑 1종). 폭발형 포탑을 새 포탑 종류로 추가하는가, 업그레이드 방향으로 넣는가?
