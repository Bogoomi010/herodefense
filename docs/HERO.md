# 영웅 기획

2026-09-26 정의. 강림·귀환 흐름은 [HERO_DESCENT.md](HERO_DESCENT.md), 필드 작업은 [HERO_INTERACTION.md](HERO_INTERACTION.md)를 따른다.

## 핵심

**플레이어 자신이 영웅이 되어 싸운다.** 포탑을 세우는 것과 별개로, 영웅으로 필드에 강림해 크립을 직접 처치한다.

## 확정

1. **영웅 기술이 따로 있다.** 영웅만의 기술이며, [플레이어 스킬트리](PLAYER_SKILL_TREE.md)(게임 전체 유틸)와는 다른 것이다.
2. **강림 효과가 있다.** 영웅이 필드에 내려올 때 효과가 발동한다.
3. **영웅 스텟이 있다.** 아이템을 사용해 높일 수 있다.
4. **기본 스텟은 5종이다.**

| 스텟 | 뜻 |
|---|---|
| 힘 | (정의 필요 — 미정 1) |
| 속도 | 이동 속도 |
| 데미지 | 공격 한 번의 피해 |
| 공격속도 | 공격 간격 (빠를수록 짧다) |
| HP | 영웅 체력 |

   - 자세한 규칙은 아래 "강림 효과" 절.
5. **무기 종류가 여럿이다.** 총, 활, 칼, 단검 등.
6. **한 스테이지에 무기 2개를 들고 들어간다.**

## 강림 효과

2026-09-26 정의·구현.

1. **기본 효과는 처음부터 있다: 스턴 + 에어본.** 영웅이 착지하는 순간, 착지 지점을 중심으로 한 강림 지역 안의 크립에게 건다.
   - **에어본:** 크립이 강림 중심에서 바깥쪽으로 날아간다. **피해는 없다.** 보스는 날아가지 않는다.
   - **뒤집힘 + 스턴 1초:** 날아간 크립은 공중에서 뒤집혀 떨어진다. **뒤집혀 떨어진 순간부터** 1초 동안 누운 채 멈춘다.
   - **복귀:** 스턴이 끝나면 바로 일어나 가까운 길로 돌아와 이동을 이어 간다([CREEP_MOVEMENT.md](CREEP_MOVEMENT.md)의 복귀와 같다).
   - **보스:** 날아가지 않고, 강림 순간 스턴 0.5초.
2. **강림 피해는 플레이어 스킬 포인트로 얻는다.** [플레이어 스킬트리](PLAYER_SKILL_TREE.md) 영웅 가지의 노드를 찍을수록 강림 지역 크립이 더 큰 피해를 입는다. 찍지 않으면 강림 피해는 0.
3. **순서:** 강림 피해 → 살아남은 크립 에어본 → 착지하며 뒤집힘 + 스턴 → 일어나 복귀.

### 수치 (초안, 테스트 플레이로 조정)

| 항목 | 값 | 코드 |
|---|---|---|
| 강림 지역 반지름 | 5m | `Hero.impactRadius` |
| 에어본 세기 | 11m/s (중심일수록 세게, 가장자리 절반). 투석기 넉백(9m/s)보다 **1.5배 멀리** 날아간다(중심 약 10m, 가장자리 약 2.4m). 가벼운 크립이 시원하게 날아가는 연출 | `Hero.impactForce` |
| 스턴 시간 | 착지부터 1초 (보스는 강림 순간부터 0.5초) | `Hero.impactStunSec`, `EnemyView.Knockback(landStunMs)` |
| 강림 피해 노드 | "강림 피해" +25, 핵심 노드 "강림 충격" +50 (강림 쿨타임 첫 노드에서 갈라짐) | `SkillEffect.DescentDamage`, `Resources/SkillTree.asset` |

- 비행은 약 0.4~0.9초, 뒤집혀 누워 있는 시간은 1초다. 투석기·영웅 공격 넉백은 뒤집히지 않는다.

## 미정

1. **힘과 데미지는 어떻게 다른가?** (예: 힘 = 넉백 세기·밀어내기, 데미지 = 한 번의 피해. 또는 힘 = 근접 무기 피해 배율, 데미지 = 모든 무기 공통 피해)
2. **영웅 기술:** 몇 개인가? 어떻게 얻는가(영웅 레벨, 영웅 스킬트리, 무기에 붙음)? 어떤 키로 쓰는가? 쿨타임이 있는가?
3. **강림 효과:** 강림 피해 외에 다른 강림 효과 노드(반지름 증가 등)가 더 있는가?
4. **아이템:** 어디서 얻는가(스테이지 보상, 상점, 크립 드롭)? 효과가 영구인가(저장 슬롯에 남음), 스테이지 안에서만인가? 한 번 쓰면 사라지는가?
5. **스텟 성장:** 아이템으로만 오르는가, 영웅 레벨도 있는가?
6. **무기:**
   - 종류별 차이 (근접/원거리, 사거리, 공격 방식, 스텟 보정)
   - 전투 중 2개를 어떻게 바꾸는가 (예: Q 또는 휠)
   - 무기를 어떻게 얻는가, 강화가 있는가
   - 스테이지 전에 2개를 고르는 화면은 어디인가 (스테이지 선택 → 무기 선택 → 시작?)
7. **HP:** 누가 영웅을 공격하는가(크립 전부, 특정 크립, 보스)? HP가 0이 되면? (예: 강제 귀환 + 강림 쿨타임 증가) 절벽에 돌아오면 회복하는가?
8. 지금의 "공격 지점 폭발 + 넉백"은 어느 무기로 남기는가, 아니면 강림 효과로 옮기는가?
