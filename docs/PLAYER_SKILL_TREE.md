# 플레이어 스킬트리 기획

2026-09-23 정의.

## 구분

| | 플레이어 스킬트리 | 영웅 스킬트리 |
|---|---|---|
| 대상 | 게임 전체(모든 포탑·영웅·오브젝트에 공통 적용) | 영웅 한 명 |
| 성격 | 유틸 | 미정 (별도 기획) |
| 성장 | 플레이어 레벨업 → 스킬 포인트 | 미정 |
| 저장 | 계정에 영구 저장 | 미정 |

포탑 개별 강화(공격속도/파워/독)는 둘 다 아니다. 영웅이 현장에서 하는 [포탑 업그레이드](TOWER_UPGRADE.md)다.

## 성장

1. 플레이어는 레벨을 가진다. 경험치가 차면 레벨이 오른다.
2. 레벨이 오를 때마다 **스킬 포인트**를 얻는다 (현재 안: 레벨당 1점).
3. **영구 기록.** 레벨, 경험치, 찍은 스킬은 저장 슬롯에 저장되고 스테이지가 끝나도 남는다. 판마다 초기화되는 스킬 포인트는 없다. 저장 슬롯 3개는 서로 완전히 다른 게임이다([STAGE.md](STAGE.md)). (2026-09-24 "계정"에서 "저장 슬롯"으로 변경)
4. 경험치 출처:
   - [나무](TREE.md) 베기
   - [스테이지](STAGE.md) 클리어 보상 (처음 클리어할 때는 스킬 포인트도 준다)
   - 그 밖의 출처는 미정

## 트리 구조

참고 이미지: 가운데에서 시작해 사방으로 뻗는 노드 그래프. 찍을수록 트리가 바깥으로 넓어진다.

1. **시작 노드.** 트리 가운데에 기본 스킬 하나가 있고, 처음부터 찍혀 있다.
2. **연결 개방.** 노드를 찍으면 선으로 이어진 이웃 노드가 열린다. 열린 노드만 찍을 수 있다.
3. **방향성(가지).** 가지마다 한 가지 주제를 가진다. 한 가지를 계속 찍으면 그 주제의 노드가 연달아 열린다. 가지는 색으로 구분한다.
4. **노드 상태:**

| 상태 | 표시 |
|---|---|
| 찍음 | 밝게 빛남 |
| 열림 (찍을 수 있음) | 가지 색 |
| 잠김 (이웃을 아직 안 찍음) | 어둡게, 아이콘 흐림 |

5. **노드 종류:**

| 종류 | 모양 | 효과 |
|---|---|---|
| 일반 | 사각형 | 작은 수치 증가. 같은 효과가 여러 개 이어진다. |
| 핵심 | 큰 마름모 | 가지의 성격을 정하는 큰 효과. 가지 중간이나 끝에 둔다. |

6. 노드 하나는 스킬 포인트 1점이다 (현재 안).

## 스킬 성격

- **유틸 위주.** 직접 피해를 올리는 것보다 게임 진행을 돕는 효과를 우선한다.
- **공통 적용.** 효과는 특정 포탑 하나가 아니라 해당하는 모든 오브젝트에 적용된다.

## 스킬 목록

확정된 스킬 (2026-09-23):

| 스킬 | 효과 | 가지 (현재 안) |
|---|---|---|
| 포탑 구역 축소 | `zoneRadius`가 노드당 기준값의 10%씩 줄어든다 | 건설 |
| 업그레이드 시간 단축 | [포탑 업그레이드](TOWER_UPGRADE.md)에 머무는 시간이 줄어든다 | 작업 |
| 영웅 강림 쿨타임 단축 | 영웅 강림 쿨타임이 줄어든다 | 영웅 |
| 경험치 획득량 증가 | 플레이어 경험치 획득량이 늘어난다 | 성장 |
| 시작 골드 | 스테이지를 시작할 때 골드를 가지고 시작한다 | 경제 |
| 골드 획득량 증가 | 스테이지 중 얻는 골드가 늘어난다 | 경제 |

추가 후보 (미확정): 나무 베기 시간 단축, 상호작용 범위 증가.

- 포탑 구역 축소는 [TOWER_PLACEMENT.md](TOWER_PLACEMENT.md#포탑-구역-축소-플레이어-스킬)의 하한(`zoneRadius ≥ footprintRadius`)을 넘지 않는다.

## 해금과 초기화

- 스킬트리는 **튜토리얼을 마치면 열린다.** 그 전에는 메뉴에 보이지 않는다.
- **스킬 초기화를 허용한다.** 무료. 찍은 노드를 모두 되돌리고 쓴 포인트를 돌려받는다. 시작 노드는 남는다.
- **메뉴 화면에서만 연다.** 스테이지 도중(인게임)에는 열 수 없다. 스테이지가 끝나고 정산을 마친 뒤 메뉴 화면에서 연다. 따라서 스테이지 중에 얻은 경험치·레벨업은 다음 스테이지부터 반영된다.

## 화면

- 스킬트리는 별도 화면에서 연다. 트리가 커지면 끌어서 이동하고 확대·축소한다.
- 화면 위쪽에 남은 스킬 포인트를 표시한다.

## 미정

- 레벨별 필요 경험치 곡선, 가지 구성, 노드 수, 효과 수치: 여러 차례 테스트로 정한다.
